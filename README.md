# ⚡ ElectroMart

ElectroMart is a full-stack online electronics shopping website developed as a TYBCA final-year project.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- PostgreSQL

## ✨ Features

- User Registration and Login
- Product Search
- Product Categories
- Product Details
- Shopping Cart
- Wishlist
- Checkout
- Order Management
- Forgot Password / OTP
- Admin Login
- Admin Dashboard
- Product Management

## 🎯 Project Objective

The main objective of ElectroMart is to develop a user-friendly online platform where users can browse electronic products, add products to their cart or wishlist, and place orders online.
